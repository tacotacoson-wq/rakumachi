# Rakumachi Finder

楽待の検索結果から詳細を順次取得し、管理費と修繕積立金を引いた利回りで絞り込む個人向けWebアプリです。

## 起動

Node.js 24、Chromiumを使用します。

```sh
cd /workspace/rakumachi
npm ci --cache /workspace/.npm-cache
npm test
npm start
```

既存の `/usr/bin/chromium` を使用します。別の場所なら `CHROMIUM_PATH` を指定してください。Chromiumがないマシンでは `npx playwright install --with-deps chromium` が必要です。

ポートは3000（`PORT`で変更可能）。クラウドのポート公開機能が利用できる場合は3000番を指定してください。

## 使い方

実質利回り（初期値10%）、取得ページ数、詳細取得上限を設定して「物件を抽出する」を押します。1〜5ページ、最大100物件まで取得可能です。楽待の検索条件を設定した検索ページURLも入力できます。利回り順で表示し、条件に合う物件をCSV保存できます。

「サンプルで試す」は架空の3物件を使用します。実物件とは混同しないでください。

実質年間収入 = 想定年間収入 − (管理費月額 + 修繕積立金月額) × 12

実質利回り% = 実質年間収入 ÷ 販売価格 × 100

費用未掲載は0円扱いしません。「なし」など明示されたゼロのみ0円とします。想定収入を表面利回りから逆算しません。判定不能と取得失敗を別表示します。固定資産税、保険、空室、融資費用等は計算に含まれません。

## 取得と制約

Playwrightで検索結果と詳細ページを開き、「Webで続きを見る」があればクリックします。詳細の表と定義リストから項目を読み取ります。取得の間隔は1.5秒、同時実行は1処理です。ログイン・CAPTCHA・アクセス制限を回避しません。サイトの利用条件に従って使用してください。

現在のクラウド環境ではネットワーク許可後も楽待の検索ページが「アクセスができません」というHTTP 403を返します。robots.txtは取得できましたが、実サイトのHTML、リンク形式、続きを見るの挙動、ページ送り、項目名は未検証で、実ページに合わせた調整が必要な可能性があります。ブラウザではクラウドプロキシ証明書の信頼エラーも発生しました。CA追加は自動承認審査で拒否されたため行っていません。TLS検証の無効化、アクセス制限の回避は行いません。実物件の抽出は、サイトが許可する環境で再検証する必要があります。

プロセス内で直近1回の結果を保持し、再起動で消去します。外部へ公開する場合には認証・ジョブ分離が別途必要です。ここでは個人利用の開発環境を対象にしています。
